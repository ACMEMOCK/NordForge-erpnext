# ERPNext Sandbox Review Checklist

## Setup

- Confirm sandbox is disposable.
- Confirm no production data is loaded.
- Create NordForge demo company.
- Create sample warehouses, items, customers, suppliers, and assets.
- Assign review users by process area.

## Review Areas

- Manufacturing work order flow
- Stock entry and stock ledger behavior
- Sales order to delivery note flow
- Asset and maintenance schedule flow
- User roles and permissions
- Data extraction options

## Exit Criteria

- Fit-gap decisions documented.
- Data-platform extraction path documented.
- Pilot scope recommended or rejected.
- No production ERP replacement decision made from sandbox alone.

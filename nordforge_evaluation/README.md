# NordForge ERPNext Evaluation

This folder tracks NordForge's fit-gap review of ERPNext as a possible ERP modernization path for selected manufacturing, inventory, asset, and service workflows.

This fork is not treated as the current production ERP source. Current NordForge data products still represent SAP-style SD, MM, WM, and TM extracts.

Evaluation scope:
- Manufacturing and work orders
- Stock ledger and warehouse movement flows
- Order-to-cash and delivery process fit
- Asset management and maintenance fit
- Data-platform extraction into Airflow, Great Expectations, OpenMetadata, Superset, and MLflow

Decision states:
- Fit
- Partial fit
- Gap
- Needs pilot
- Out of scope
